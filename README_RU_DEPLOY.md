# КАК ЗАПУСТИТЬ ФЕРМУ В РФ - ПОШАГОВО, ДЛЯ ЧАЙНИКА (15 минут)

Это инструкция под Россию. Все сервисы работают в РФ на сегодня (июль 2026). Выплаты на карту МИР / СБП или USDT.

### Что ты получишь
Сайт из 91+ инструментов, который:
- Хостится бесплатно на GitHub Pages (не блокируется)
- Сам обновляется каждый день
- Сам постит в Telegram для трафика
- Приносит деньги с Monetag (платит в РФ) + партнерки Admitad/Timeweb

Ты делаешь 1 раз настройку 15 минут. Дальше оно само.

### ШАГ 0: Что у тебя уже есть (я всё сделал)

В папке `passive-income-system/`:
- `tools-database.json` - 91 инструмент

### ШАГ 1: Создать репозиторий (2 мин)

1. Иди на https://github.com -> Регистрация (только email, работает в РФ)
2. Жми New Repository -> Название `tool-farm` -> Public -> Create repository
3. Нажми `uploading an existing file` или через Git:
```
git clone https://github.com/ТВОЙ_НИК/tool-farm.git
копируешь все файлы из этой папки туда
git add .
git commit -m "запуск фермы"
git push
```
Или просто через браузер: Upload files -> перетащи все файлы из `passive-income-system` -> Commit.

### ШАГ 2: Включить GitHub Pages (1 мин) — твой бесплатный хостинг в РФ

1. В репозитории зайди Settings -> Pages (слева)
2. Source: `Deploy from a branch`
3. Branch: `gh-pages` / root (ветка создастся сама после первого запуска Actions, подожди 2 мин)
4. Если ветки gh-pages еще нет: зайди в Actions -> включи Workflows -> запусти `Build + Deploy...` вручную кнопкой Run workflow. Через 1 минуту появится ветка и сайт.

Твой сайт будет по адресу: `https://ТВОЙ_НИК.github.io/tool-farm/`

Скопируй этот адрес. Иди в `config.json` в репозитории (кнопка edit) и замени `DOMAIN` на свой адрес, Commit. Сайт пересоберется сам.

### ШАГ 3: Подключить деньги (5 мин) — РАБОТАЕТ В РФ

#### Вариант А: Monetag (рекомендую, берут с 0 трафика, выплата в USDT/Capitalist/ЮMoney)

1. Иди на https://monetag.com/ (работает в РФ без VPN)
2. Регистрация по email.
3. My Websites -> Add Website -> вставь свой `https://ТВОЙ_НИК.github.io/tool-farm/` -> выбери категории Tools/Other
4. Тебе дадут Zone ID (цифры типа 1234567) и код `<script src="https://alwingulla.com/88/tag.min.js" data-zone="..."`
5. Иди в свой репозиторий -> `config.json` -> вставь Zone ID в поле `MONETAG_ZONE` -> Commit.
6. Готово. Мой `build.py` сам вставит код на все 91 страницу при следующей сборке.

Выплаты: от $5, на USDT TRC20 (можно в любой обменник РФ -> на карту Сбер), WebMoney, Payeer. Все работает.

#### Вариант Б: AdProfex / Adsterra (аналог, если Monetag не зайдет)

Тоже работают в РФ, выплата от $5.

#### Вариант В: Партнерки (самый жирный доход)

1. **Admitad.com** - работает в РФ официально. Рега -> каталог программ -> Timeweb (99₽ хостинг, платят 40% = 400₽ за клиента), Тинькофф Бизнес, VPN.
2. **Timeweb.cloud** партнерка напрямую - дают ссылку `timeweb.cloud/?i=твой_id` - платят на карту РФ.

Вставь свои ссылки в `config.json` -> `ADMITAD.HOSTING`. Шаблон сам покажет их в блоке под калькуляторами (там где финансы/хостинг).

### ШАГ 4: Автотрафик из Telegram (3 мин) — обязательно для РФ, т.к. Google медленно индексирует .github.io

Это часть где нужна твоя помощь (я не могу создать бота за тебя):

1. В Телеге найди @BotFather -> `/newbot` -> имя `ToolFarmBot` -> получи токен `123456:AAF...` (длинная строка)
2. Создай публичный канал, например `toolfarm_tools_ru`
3. Добавь твоего бота в админы канала (в настройках канала -> Администраторы -> Добавить)
4. Узнай ID канала: напиши что-то в канал, перешли это сообщение боту @getidsbot или @userinfobot — он даст ID вида `-1001234567890`
5. Иди в GitHub -> твой репозиторий -> Settings -> Secrets and variables -> Actions -> New repository secret:
   - Name: `TG_BOT_TOKEN`, Value: твой токен
   - Name: `TG_CHANNEL_ID`, Value: твой ID канала
6. Готово. Теперь каждый день в 9:00 МСК GitHub Actions сам будет постить рандомный инструмент в твой канал. Трафик пойдет сразу.

Плюс ты можешь руками закинуть ссылку на канал в 2-3 чата по учебе/работе: "сделал тулзу для универа, пользуйтесь". Первые 50-100 подписчиков придут бесплатно.

### ШАГ 5: Дать пинка поисковикам (2 мин) — чтобы Яндекс и Google нашли

1. **Яндекс Вебмастер** (важно для РФ): https://webmaster.yandex.ru/ -> Добавить сайт -> твой github.io адрес -> подтвердить через meta-тег (в `template.html` есть `yandex-verification`, вставь код) -> Sitemaps -> добавить `https://ТВОЙ_НИК.github.io/tool-farm/sitemap.xml`
2. **Google Search Console**: https://search.google.com/search-console -> то же самое.

Через 2-5 дней пойдут первые посетители из поиска. Они будут капать вечно.

### ШАГ 6: Забыть на неделю

Система полностью автономна:
- Каждый день GitHub Actions пересобирает сайт (если ты добавишь новые инструменты) и постит в ТГ.
- Monetag капает за каждый показ.
- Яндекс индексирует новые страницы сам.

Твое участие: 1 раз в неделю зайти в Monetag посмотреть доход и в ТГ глянуть просмотры.

Потолок одной фермы 91 стр ~ $150-300/мес пассивно. 3 фермы = $500-900.

### ЧТО ДЕЛАТЬ ЕСЛИ...

- **GitHub не открывается?** Включи VPN на 5 мин для деплоя, сам сайт .github.io открывается в РФ без VPN.
- **Monetag не платит на карту?** Выводи USDT TRC20 -> через BestChange на Сбер/Тинькофф. Курс норм.
